## 🚀 About The Project

**QuoteVerse AI** ek next-level web application hai jahan aap pre-built wisdom explore kar sakte hain, categories ke mutabiq quotes filter kar sakte hain, aur **Nova AI Bot** ki madad se real-time par bilkul fresh, unique thoughts generate kar sakte hain! 

Yeh project kisi heavy framework (jaise React ya Vue) ke bagair pure **Vanilla JavaScript aur Tailwind CSS (CDN)** par banaya gaya hai taake isay chalana aur run karna bilkul aasan ho.

---

## ✨ Key Features

- 🤖 **Nova AI Bot Generator**: Keyword aur Tone select karein aur instant smart quotes generate karein (English & Roman Urdu support ke sath!).
- 💎 **Soft Light Glassmorphism UI**: Warm alabaster background, indigo/violet accents, aur modern glass panels.
- 📌 **Persistent LocalStorage**: Apni pasandeeda quotes ko bookmark/save karein—page reload hone par bhi data gayab nahi hoga!
- 🗂️ **Dynamic Categories**: Stoicism, Technology, Philosophy, aur Creativity ke mutabiq quotes ko filter karein.
- 📋 **One-Click Copy**: Kisi bhi quote ko clipboard par copy karne ka aasan option.

---

## 🛠️ Built With

* **HTML5** - Structure & Markup
* **Tailwind CSS (CDN)** - Modern Utility-First Styling
* **Vanilla JavaScript (ES6)** - Application Logic & State Management
* **Browser LocalStorage** - Persistent Data Storage
